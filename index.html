ig-template-mii-kds

HL7 IG-Publisher template package with MII branding — Forschungsgruppe Digital Health, TU Dresden.

This is the template package: the branding, layout, and rendering machinery that MII KDS module Implementation Guides build on. To start a module, use the MII KDS module template instead, which vendors this package.
